# Security policy

## Supported versions

Security fixes go into the latest release only.
Update to the latest version before you report a problem.

## Report a vulnerability

Please do not open a public issue for a security problem.

Report it in private through GitHub:

1. Open the [Security tab](https://github.com/edsml-jz2321/QuoteMem/security) of this repository.
2. Choose **Report a vulnerability**.
3. Describe the problem, the version you use, and the steps to reproduce it.

You get an answer in the same private report.
